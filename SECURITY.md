# Sécurité

## Signaler un problème

Pour une vulnérabilité de sécurité réelle, évite de publier immédiatement les détails dans une issue publique. Contacte d'abord le mainteneur du projet via un canal privé disponible sur le profil GitHub du dépôt.

## Bonnes pratiques

Ne partage jamais dans une issue ou une Pull Request :

- cookie de session ;
- jeton d'authentification ;
- mot de passe ;
- code OTP ;
- adresse e-mail temporaire encore valide ;
- capture contenant des données personnelles.
